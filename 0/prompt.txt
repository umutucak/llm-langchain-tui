2. **Key Technical Concepts:**
   - LangChain v1 `create_agent` → returns a `CompiledStateGraph`; middleware compiles into that graph.
   - **Middleware hook taxonomy**: `before_model`/`after_model` become **real graph nodes** (and inherit routing edges); `wrap_model_call`/`wrap_tool_call` are **wrappers, invisible in the topology**. Verified by rendering mermaid graphs with each.
   - **`after_model` hooks execute in REVERSE list order** (onion unwinding) — load-bearing ordering dependency.
   - `@after_model(can_jump_to=["model"])` decorator; `JumpTo = Literal['tools','model','end']`; `jump_to` returned in the state dict.
   - `add_messages` reducer replaces messages **by matching `id`**.
   - `.tool_calls` does **NOT** derive from `content` blocks — must be passed explicitly to `AIMessage(...)`.
   - `ToolNode` executes **all** `tool_calls` concurrently via `executor.map`, drains to a list, and returns **one** combined state update — the model never sees a partial set.
   - `json.JSONDecoder().raw_decode()` walks successive JSON objects out of a concatenated string.
   - `output_version="v1"` routes messages through `_convert_from_v1_to_ollama` (langchain_ollama/_compat.py), which is a **whitelist** — unknown block types (`reasoning`, `tool_call`, `invalid_tool_call`) are **silently skipped**, not raised on. The raw `_convert_messages_to_ollama_messages` path *does* raise.
   - `ToolErrorMiddleware(on_error, tools=[...])` — `on_error(exc, request) -> str | None`; returning `None` propagates.
   - `ToolCallLimitMiddleware(tool_name, run_limit, thread_limit, exit_behavior)` — `run_limit` is per-turn, `thread_limit` per-conversation; `exit_behavior="continue"` blocks excess calls with a per-`tool_call_id` error ToolMessage.
   - Milvus Lite: `query()` silently truncates at the `limit` (must use `query_iterator` for full scans).
